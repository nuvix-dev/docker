# Nuvix Docker

This project uses Docker Compose to manage services.

## Getting Started

1. Install [Docker](https://docs.docker.com/get-docker/) and [Docker Compose](https://docs.docker.com/compose/install/).
2. Run:
   ```sh
   docker-compose up
   ```
